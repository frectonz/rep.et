# rep.et

A civic web app for finding your elected representative in Ethiopia's House of Peoples' Representatives (HOPR). Built with data from the 6th National Election.

**Live at [rep.et](https://rep.et)**

## Data

Election data comes from the official 6th National Election results published by the National Election Board of Ethiopia (NEBE). The dataset covers 480 of 547 constituencies.

Geographic coordinates were geocoded from constituency names using Wikidata, the Humanitarian Data Exchange (HDX), and manual corrections. These are approximate point locations, not official boundary data.

## Disclaimer

This is an independent, unofficial, open-source project. It is not affiliated with or endorsed by the Ethiopian government, the National Election Board of Ethiopia, or any political party. Data is provided as-is for informational purposes.
